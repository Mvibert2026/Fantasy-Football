Standing checks — apply to every screenshot

  • Nulls. Any place a 0 or 0% appears where "not computed" is the honest answer. This is the single highest-value thing to catch.
  • Typography. Mono for measurements only. Position and team codes are labels — sans, small, letter-spaced. Everything in one monospace texture is what made early builds read as a terminal.
  • Density. Count rows visible per screen. If it feels roomy, it has drifted.
  • Colour alone. Any signal carried only by colour, with no redundant cue. Squint or screenshot in greyscale to test it.
  • Radius. 4–6px on chrome, zero on data cells and table rows.
Report format: the filename, and one line on anything that failed a check. No prose needed — I'll turn it into threads.
